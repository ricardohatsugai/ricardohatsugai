Sou profissional da área comercial com mais de **25 anos de experiência** no mercado B2B, atuando nos segmentos de Materiais de Construção, Ferragens, Ferramentas, MRO, Home Centers, Atacados e Indústrias.

Nos últimos anos passei a concentrar meus estudos no desenvolvimento de software, unindo conhecimento de negócios com engenharia de software para criar aplicações robustas, escaláveis e voltadas às necessidades reais das empresas.

Meu principal objetivo é desenvolver sistemas que simplifiquem processos comerciais e forneçam informações confiáveis para a tomada de decisão.

# 📚 Projeto Legado

## SGV8

O **SGV8** foi o primeiro grande projeto de sistema de gestão comercial desenvolvido durante meu processo de aprendizado.
